# 나의 오피스

내 팀이 출근하고, 자리에서 일하고, 회의실에 모이고, 대표실로 보고하러 오는 **나만의 픽셀 사무실**입니다.
일을 맡기면 해당 팀 팀장이 대표실로 지시를 받으러 오고, 팀원들이 자리에서 일을 진행한 뒤 결과를 보고하러 옵니다.

설치 후 바로 돌아가며, 서버나 외부 연동은 필요 없습니다. 모든 설정과 맡긴 일은 브라우저에 저장됩니다.

## 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
npm run dev      # http://localhost:5173
```

배포용 파일은 `npm run build` → `dist/` 폴더에 만들어집니다. 정적 파일이라 어디에 올려도 됩니다.

`main`에 올라가면 GitHub Actions가 자동으로 빌드해서 GitHub Pages에 배포합니다 (`.github/workflows/deploy-pages.yml`).
처음 한 번은 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 바꿔야 합니다.

## 쓰는 법

| 화면 | 할 수 있는 일 |
|---|---|
| **사무실** | ‘출근시키기’로 하루 시작 · 속도(1~8배) 조절 · 지도 드래그/휠 확대 · 직원 클릭 시 프로필 |
| **업무 맡기기** | 할 일·팀·분량을 정해 맡기기. ‘내 승인 받기’를 켜면 끝난 뒤 **결재함**으로 올라옵니다 |
| **지시창** | “마케팅팀 이번 주 게시물 정리해줘”, “회의 소집”, “커피 타임”, “현황 알려줘”, “윤하람 뭐해?”, “퇴근” |
| **업무 보드** | 팀별 진행 상태와 업무 목록, 상태별 거르기 |
| **설정** | 사무실 이름·로고·출퇴근 시각, 내 캐릭터, 팀(최대 16개)과 직원(팀당 8명) 추가·수정·삭제, JSON 내보내기/불러오기 |

하루 일정: 출근 → 10시 스탠드업 회의 → 12시 점심(라운지) → 15시 커피 타임 → 퇴근 30분 전 마무리 보고 → 퇴근 → 하루 브리핑.
끝나지 않은 내 지시는 다음 날로 이어집니다.

## 구조

```
src/
  config/      기본 회사(defaults.ts), 설정 타입, 브라우저 저장
  engine/      world.ts(지도 자동 배치) · path.ts(A* 길찾기) · sim.ts(하루·업무 시뮬레이션) · render.ts(캔버스)
  components/  사무실 캔버스, 오른쪽 칸(결재함·업무 맡기기·지시창·기록), 업무 보드, 설정, 모달
```

기본 회사를 코드로 바꾸고 싶다면 `src/config/defaults.ts` 하나만 고치면 됩니다.
팀 수는 자유이며 방은 4열로 자동 배치됩니다.
